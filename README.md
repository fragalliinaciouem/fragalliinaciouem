## 🗂️ Como este espaço está organizado

Por enquanto só temos o repositório de Estruturas de Dados:

```
📁 estruturas-de-dados/
 ├── 📁 Conceitos Básicos/
 ├── 📁 Desafios/
```

Conforme o curso avança, é bem provável que isso vire vários repositórios — um por disciplina ou por semestre. Por ora, o conteúdo dentro das pastas costuma se dividir assim:

| Tipo de conteúdo | O que é |
|---|---|
| 📝 **Listas de exercícios** | Resoluções de problemas propostos em aula, geralmente de lógica e algoritmos |
| 🧩 **Trabalhos avaliativos** | Projetos individuais ou em grupo, entregues como parte da nota da disciplina |
| 🔬 **Estudos livres** | Códigos de experimentação — testando um conceito visto em aula, sem compromisso de "produto final" |
